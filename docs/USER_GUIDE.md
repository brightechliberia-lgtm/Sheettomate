# User guide

Sheettomate is a marketplace and learning hub for Excel and Google Sheets templates.

## Get started

1. Open the app (local: http://localhost:5173).
2. Register or sign in. Demo: `learner@sheettomate.com` / `ChangeMe123!`.
3. Browse templates and courses. Purchases in development use **sandbox** payments (Orange Money / BanffPay mock)—no real card numbers.
4. Install the PWA from the browser for fullscreen and offline catalog caching.
5. Community: profiles, comments, forums, challenges (`/community`). Follow [guidelines](/guidelines).
6. Creators can sell templates and use **Automations** (`/automations`) for reports and webhooks.

Support: use the site contact/support email configured by your operator.
